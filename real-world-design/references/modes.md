# Modes

Scegli una modalità. Non mescolare i default visivi.

## game

Trigger: HUD, inventario, shop, skill tree, pause, load/save, dialogue, quest log, crafting, map, diegetic, gacha, battle, mobile game UI, title screen.

Piattaforme: PC/console overlay, o telefono (thumb zone, notch, 44px).

Source obbligatorie: Game UI Database, Interface In Game. 2–3 titoli nominati nel brief.

Vietato come scheletro: shadcn Card, bento, navbar SaaS, Inter, indigo, Lucide-as-weapon, Aceternity shader.

Output: HTML/CSS mock. React solo se richiesto.

## product-app

Trigger: app telefono, settings, onboarding, chat, agent UI, dashboard prodotto, lista, composer, approval.

Source: 2–3 app reali (iOS/Android/web analoghe), poi Beautiful UI per stati agent, 21st per pezzi.

Kit SaaS = ingredienti restyled sui token, non look finale.

Output: mock HTML/CSS, poi React+Tailwind.

## marketing

Trigger: landing, hero, pricing, changelog visivo, waitlist, studio site.

Prima la direzione (un materiale, un type pairing, un accento). Poi al massimo un blocco Aceternity.

Vietato: hero + 3 feature cards + gradient viola; bento 3×2 di default.

Output: mock, poi React+Tailwind.

## Tie-breakers

| Brief | Mode |
|---|---|
| "HUD come Hades su telefono" | game |
| "shop gacha mobile" | game |
| "app inventario palestra" | product-app |
| "landing del gioco" | marketing |
| "settings in-game" | game |
| "settings dell'app launcher" | product-app |

Chiedi una volta solo se il brief contiene sia "gioco" sia "landing/saas" senza priorità.
